# Multimodal Biometric Recognition System

## 📌 About the Project

The **Multimodal Biometric Recognition System** is a biometric authentication project designed to provide secure and reliable user recognition using multiple biometric characteristics.

The system combines **Face Recognition, Iris Recognition, and Finger Vein Recognition** to improve the reliability and security of biometric authentication. Deep Learning, Image Processing, and Computer Vision techniques are used for biometric feature extraction and recognition.

## 🎯 Objectives

- To develop a secure biometric authentication system.
- To recognize users using multiple biometric characteristics.
- To perform biometric image preprocessing and feature extraction.
- To improve recognition reliability using multimodal biometric data.
- To apply Deep Learning and Computer Vision techniques to biometric recognition.

## 🔐 Biometric Modalities

The system includes the following biometric modalities:

- 👤 Face Recognition
- 👁️ Iris Recognition
- 🖐️ Finger Vein Recognition

By using multiple biometric characteristics, the system aims to provide more reliable authentication compared with using a single biometric modality.
